Top 5 critical & high issues

  1. Invalid Event schema. /events/flowconf-2026/ ships startDate:"" — fails Google's Event rich-result validation outright.
  2. Contact page regressed. Mobile Performance fell to 68 (TBT 3,200ms) — the "deferred" Cal.com widget still blocks the main thread once it fires, on the highest-intent page.
  3. Canonical/trailing-slash mismatch on ~57 of 58 pages — canonicals point to a non-matching URL with no redirect either way.
  4. /video/ is indexable thin content — no noindex, no description, title is literally "video".
  5. 8 category hubs share one meta description — a mail-merge template across 14% of indexed URLs.

Top 5 quick wins

  1. Fix the "three years" (llms.txt) vs. "four years" (homepage) experience contradiction — one-line edit, twice.
  2. Add /video and /style-guide to the sitemap filter; noindex video.astro.
  3. Guard startDate/image in buildEventLd() the way datePublished already is.
  4. Write 8 unique meta descriptions for the resource-category hubs — a CMS field edit each.
  5. Shorten the homepage meta description (185 → ≤160 chars) and 3 over-length case-study ones.

Technical SEO

74 / 100 · 22% weight
Holding up wellrobots.txt correctly allows AI-citation bots and blocks AI-training bots; sitemap validates; HTTPS + HSTS enforced everywhere; the four thin taxonomy routes stay noindexed and out of the sitemap; fully server-rendered with no JS-rendering dependency; real 404s.
High

Canonical URL / actual URL mismatch, sitewide

canonicalFor() in src/lib/seo/site.ts strips the trailing slash, but the site serves and sitemaps every page with one — both forms are live 200s with no redirect between them. Affects ~57 of 58 URLs.

Fix: make canonicalFor()/absUrl() preserve the trailing slash.

High

/video/ is fully indexable thin content

No noindex, no meta description, <title>video</title>, zero structured data — and it's in the live sitemap. An orphaned leftover Webflow-export page, unlinked from any navigation.

Fix: set noindex: true, exclude from the sitemap filter, or give it real content.

Medium

/style-guide/ noindexed but still submitted in the sitemap

Correctly noindex in-page, but missed by the astro.config.mjs sitemap filter that already excludes /industry/, /tech-stack/, /authors/, /testimonials/.

Fix: add /style-guide to the same filter.

Medium

Two-hop redirect chain on the bare apex

http://srdjan-jovic.com → https://srdjan-jovic.com → https://www.srdjan-jovic.com — a Vercel domain-config chain, one hop longer than necessary.

Fix: point the apex redirect straight at the final www HTTPS URL.

Medium

No hardening headers beyond HSTS

No CSP, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, or Permissions-Policy on any page checked.

Fix: add via a Vercel headers config; extend HSTS with includeSubDomains; preload.

High

Homepage mobile CWV flagged in lab data

LCP 3.06s, TBT 1,222ms, Performance 69/100 on this run. See the Performance section for the fuller, multi-page picture and CrUX availability status.

Fix: see Performance below.

Low

No IndexNow integration; sitemap has no <lastmod>

Real Last-Modified headers exist per page but aren't surfaced in the sitemap.

Fix: wire lastmod from Sanity's _updatedAt; add an IndexNow ping on publish.

Critical

Contact page's Cal.com widget still blocks the main thread

The "defer" from a prior fix changes when the widget's 3.6s/2MB cost lands, not whether it happens — TBT is now worse than the pre-fix baseline. A duplicate Cal.com avatar request was also found (~77KB wasted).

Fix: load Cal.com only on real user intent — click-to-load or a genuine intersection-observer threshold, not idle-callback-on-page-load.

High

Render-blocking global stylesheet, ~70% unused per page

BaseLayout.css costs 80–320ms of first-paint delay on every template — no page uses more than ~30% of it.

Fix: split into per-route/critical CSS, or defer non-critical rules.

High

Homepage desktop measured below its recorded baseline

83 vs. a previously recorded 92 — worth 2–3 repeat runs to rule out lab noise; forced-reflow-insight still fails on both strategies.

Fix: re-measure, then hunt the remaining geometry-read-after-write call if it reproduces.

Medium

GA4/GTM: a consistent 130–410ms main-thread cost sitewide

Expected for a tag manager, but ~72KB of its ~170KB payload is unused on every page; highest on /resources/ desktop (410ms).

Fix: consider loading gtag.js directly to skip the GTM container overhead.

Info

CLS is ~0 everywhere; case-study template and events now near-perfect

All fixes from the prior optimization pass are holding, and two templates now exceed their post-fix baselines.

Flagged for the a11y owner, not performance: color-contrast fails on body text and a newsletter-modal input on the resource-article template, ratio as low as 1.47:1.
